# Tailwind Ad Package - What's Included

This package contains everything you need to send to an ad agency for producing a 15-second promotional video for Tailwind.

## Files Included

### 1. AD_CREATIVE_BRIEF.md
**The main creative brief** with:
- Two complete 15-second scripts
- Visual style guide
- Music/audio direction
- Platform specifications (Instagram, YouTube, Twitter)
- Budget options
- Timeline suggestions
- Questions to ask agencies

### 2. AD_VISUAL_GUIDE.md
**Visual reference guide** with:
- Color palette (hex codes)
- Typography specifications
- Screenshot mockups (what to record)
- Motion graphics guidelines
- Frame compositions
- Filming guidelines
- End card variations

### 3. TEAM_DEMO.md
**Internal team demo document** showing:
- All app features explained
- Use cases
- Privacy-first approach
- TestFlight installation guide

### 4. README.md
**Full project documentation** with:
- Complete feature list
- Technical stack
- Privacy policy reference
- Roadmap

### 5. APP_STORE_DESCRIPTION.md
**Marketing copy** including:
- App Store description (4000 chars)
- Keywords
- Promotional text
- Subtitle

## Next Steps

### Before Sending to Agency

1. **Record App Screens** (Instructions in AD_VISUAL_GUIDE.md)
   - Main ride screen (landscape, 30s)
   - Segment detection (15s)
   - Speed heatmap (15s)
   - Training load chart (15s)
   - Bike maintenance (15s)

2. **Export App Icon**
   - 1024x1024 PNG
   - High resolution
   - Transparent or black background

3. **Gather Assets**
   - App icon
   - Screen recordings
   - Any logo variations you have

### Sending to Agency

Include:
- ✅ AD_CREATIVE_BRIEF.md (main brief)
- ✅ AD_VISUAL_GUIDE.md (visual reference)
- ✅ Screen recordings you create
- ✅ App icon (1024x1024 PNG)
- ✅ APP_STORE_DESCRIPTION.md (for copy reference)

Optional:
- TEAM_DEMO.md (if they want context)
- README.md (technical background)

### Questions to Ask

From AD_CREATIVE_BRIEF.md, ask agencies:
1. Portfolio examples of app promo ads?
2. Stock footage or custom filming?
3. How many revision rounds included?
4. Can you deliver all platform formats?
5. Timeline estimate?
6. Is music licensing included?
7. Voice talent included or separate?
8. Do I own all final files with unlimited usage?

### Budget Guidance

**Low Budget**: $500-1,500
- Stock footage only
- Your screen recordings
- Simple motion graphics
- Royalty-free music

**Mid Budget**: $1,500-3,500
- Mix of custom + stock
- Professional screen capture
- Custom motion graphics
- Licensed music
- Professional voiceover

**High Budget**: $3,500+
- Full custom shoot
- Drone footage
- Advanced motion graphics
- Original music
- Pro cyclist talent

## Platform Deliverables to Request

Ask for all these formats:

### Instagram/Facebook/TikTok
- Format: Vertical (9:16)
- Resolution: 1080x1920
- Duration: 15 seconds
- File: MP4, H.264, max 30MB

### YouTube Pre-roll
- Format: Horizontal (16:9)
- Resolution: 1920x1080
- Duration: 15 seconds
- File: MP4, H.264, max 50MB

### Twitter/X
- Format: Square (1:1)
- Resolution: 1080x1080
- Duration: 15 seconds
- File: MP4, max 512MB
