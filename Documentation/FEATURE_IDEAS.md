# Tailwind Feature Ideas & Backlog

## High Priority

### Bike Maintenance Dashboard
**Status**: Planned
**Description**: Create a comprehensive bike dashboard that shows all maintenance items with visual progress indicators.

**Features**:
- Progress bars showing usage vs trigger point for each maintenance item
- Visual states:
  - Green: Good condition (< 75% to trigger)
  - Yellow/Orange: Due soon (75-100% to trigger)
  - Red: Overdue (past trigger point)
- Quick glance at bike health
- Tap item to view details or mark as completed
- Shows days/miles until next service
- Group by component type (drivetrain, wheels, brakes, etc.)
- Option to view maintenance history per component

**UI Concepts**:
- Card-based layout with component icons
- Circular progress indicators or horizontal bars
- "Bike Health Score" summary at top
- Quick action buttons: "Service Done", "Reset Counter"

**Priority**: High - makes maintenance tracking actually useful at a glance
